# Plugin pack

Здесь лежат плагины, которые бот автоматически устанавливает в `plugins/`
при запуске (см. `_sync_plugin_pack()` в `main.py`).

## Как это работает

* при старте бот копирует `*.py` из этого каталога в `plugins/`, если файла там нет;
* если файл есть и его не редактировали — он обновляется вместе с ботом;
* если файл в `plugins/` отличается от последней поставленной версии
  (то есть вы его правили) — он **не перезаписывается**;
* состояние синхронизации: `storage/cache/plugin_pack.json`.

## Playerok Lots Loader (`playerok_lots_loader.py`)

Загрузка лотов Playerok из JSON, обложки к каждому лоту, автоподнятие.

Команды в Telegram:

| Команда | Что делает |
| --- | --- |
| `/pk_lots` | справка и меню |
| `/pk_cat Roblox` | найти игру по названию |
| `/pk_cat <id игры>` | показать категории игры и готовые команды |
| `/pk_cat <id категории>` | подсказать шаблон для этой категории |
| `/pk_template <id категории>` | получить готовый JSON-шаблон с полями и опциями |
| `/pk_template <id игры> <slug>` | то же без ID категории, например `… accounts` |
| `/pk_upload` | отправить JSON — бот покажет предпросмотр и попросит подтверждение |
| `/pk_cover 1` | загрузить обложку №1 (сохраняется в `storage/products/covers/1.*`) |
| `/pk_cover 1 2 3` | сразу несколько обложек: бот попросит 3 картинки по очереди |
| `/pk_options <id категории>` | характеристики категории и допустимые значения |
| `/pk_raise` | включить/выключить автоподнятие |
| `/pk_raise_now` | поднять все активные лоты сейчас |

Формат JSON: см. `playerok_lots_example.json` и вывод `/pk_template`.

### Обложки

* у лота — `"images": ["1", "2"]` (до **10** штук, ограничение Playerok);
* одна строка тоже работает: `"image": "1"`;
* в шапке файла — общая обложка для лотов без своей;
* номер (`"1"` → `storage/products/covers/1.png`), имя файла с расширением или путь.

### Характеристики (`options`)

Пишите **по одному значению на группу** — страна одна, игра одна:

```json
"options": {"Пол": "male", "Игра": "blox-fruits", "Страна": "russia"}
```

Ключом можно писать название группы («Страна»), название опции («Россия») или
`field` (`country`). Список допустимых значений присылает `/pk_template` (вторым
сообщением) и `/pk_options`. Неверное значение не уходит на сервер — в
предпросмотре будет подсказка с примерами, а лот останется без этой характеристики.

### Черновики

`"publish": false` в шапке файла — вся партия черновиками; в отдельном лоте —
только этот лот. Флаг из JSON важнее настройки `publish` в файле настроек.

### Как найти ID категории

ID в Playerok — это UUID (`1ecc48ce-4f1a-6531-300d-9faaa8c3ab04`), а не число.

1. `/pk_cat Roblox` — поиск игры по названию, под каждой игрой будет готовая команда;
2. `/pk_cat <id игры>` — список категорий, под каждой — готовая команда `/pk_template <id>`;
3. `/pk_template <id категории>` — шаблон. Категория «Аккаунты» — это и есть нужный ID.

Без ID категории: `/pk_template <id игры> accounts` — плагин сам найдёт категорию по slug.

Ещё вариант — свои уже выставленные лоты: `storage/cache/listed_lots.json`, поля
`category_id`, `category_slug`, `category_name`.

### Настройки

Файл: `storage/plugins/playerok_lots_loader_settings.json`

| Ключ | По умолчанию | Значение |
| --- | --- | --- |
| `delay` | `1.5` | пауза между созданием лотов, сек |
| `publish` | `true` | публиковать сразу (если в JSON не указано иное) |
| `allow_premium` | `false` | разрешить платное (премиум) поднятие |
| `premium_max_price` | `0` | максимальная цена премиум-поднятия, `0` — без ограничения |
| `default_image` | `""` | обложка по умолчанию для лотов без `image` |
| `auto_raise` | `false` | автоподнятие включено |
| `raise_interval_minutes` | `240` | как часто поднимать каждый лот, мин |
