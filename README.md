## 🤖 **Возможности**

- Автовыдача товаров.
- Автоответ на заготовленные команды.
- Автовосстановление лотов после продажи.

### 📦 Готовый плагин: массовая загрузка лотов из JSON

В репозитории есть плагин `playerok_lots_loader` (каталог `plugin_pack/`).
При запуске бот сам копирует его в `plugins/`, вручную ничего устанавливать не нужно.

Что умеет:

* создаёт много лотов Playerok из одного JSON-файла;
* у каждого лота своя обложка (`storage/products/covers/1.png`, `2.png`, …);
* заполняет поля данных и опции по человеческим названиям («Логин», «Платформа»);
* публикует сразу или оставляет черновиками;
* автоматически поднимает лоты по расписанию (бесплатным приоритетом;
  платный — только если разрешить в настройках).

Быстрый старт в Telegram:

1. `/pk_cat Roblox` → найдите игру, затем `/pk_cat <id игры>` → бот покажет категории
   (например, «Аккаунты») и готовые команды. ID в Playerok — это UUID.
2. `/pk_template <id категории>` (или короче `/pk_template <id игры> accounts`) →
   бот пришлёт готовый JSON-шаблон с характеристиками и полями категории.
3. Заполните лоты, положите обложки: `/pk_cover 1` и т. д.
4. `/pk_upload` → отправьте JSON → проверьте предпросмотр → «Создать».
5. `/pk_raise` — включить автоподнятие, `/pk_raise_now` — поднять всё сразу.

Подробности: [plugin_pack/README.md](plugin_pack/README.md),
пример файла — [plugin_pack/playerok_lots_example.json](plugin_pack/playerok_lots_example.json).
Самопроверка без реального аккаунта: `python scripts/selftest_lots_plugin.py`.

## ⬇️ Установка

Арендовать виртуальный сервер можно на [Bhost.fun](https://bhost.fun/r/7777777)

### 🧱 Структура репозитория

Код бота лежит в корне репозитория: `main.py` (точка входа), `requirements.txt`
и каталоги `PlayerokAPI/`, `Utils/`, `tg_bot/`, `locales/`, `scripts/`, `configs/`.
Главный файл для хостинга — `main.py`.

### ☁️ Хостинг ботов (Bothost)

Пошаговая инструкция: [BOTHOST.md](BOTHOST.md). Кратко: язык Python, главный файл
`main.py`, переменные окружения `POC_PLAYEROK_TOKEN` и `POC_PASSWORD` (`BOT_TOKEN`
передаёт хостинг). Данные (`configs`, `storage`, `plugins`, `logs`) хранятся в
`DATA_DIR` и не теряются при пересборке.

### 🔷 Windows

1. Скачайте и установите Python 3.11.0.
    1. При установке поставьте галочку у `Add python.exe to PATH` на первом экране установки.
2. Скачайте [Playerok Cardinal](https://github.com/KaDerix/PlayerokCardinal)
3. Перенесите архив `PlayerokCardinal-main.zip` в нужное Вам место и распакуйте его.
4. Перейдите в папку `PlayerokCardinal-main`.
5. Запустите файл `Setup.bat`. Дождитесь окончания загрузки пакетов.
6. Закройте командную строку и запустите файл `Start.bat`.

### ♨️ Linux (Ubuntu)

1. Выполните команду: `wget https://raw.githubusercontent.com/KaDerix/PlayerokCardinal/main/install-poc.sh -O install-poc.sh && bash install-poc.sh`
2. Следуйте инструкциям установщика. Данный скрипт автоматически установит всё необходимое и запустит бота как фоновый процесс.

## 🩺 Диагностика и типичные ошибки

**`ModuleNotFoundError: No module named '...'`** — у того Python, которым запускается бот, не установлены зависимости
(частая причина: `pip install` сделан в другом окружении). Проверить и исправить:

```bash
# тем же интерпретатором, что и в сервисе / контейнере
python scripts/check_env.py
python -m pip install -U -r requirements.txt
python -m pip install -U -r requirements-tls.txt   # необязательно (см. ниже)
```

На сервере, установленном через `install-poc.sh`, то же самое делает `sudo pocctl doctor`.

**Windows:** откройте `Setup.bat` (он ставит зависимости в тот же Python, из которого запускается `Start.bat`).

**Про `curl_cffi`.** Это рекомендуемый HTTP-бэкенд с TLS-фингерпринтом браузера, но он **не обязателен**:
если пакет не ставится на вашем хосте (нет wheel под musl/старый glibc/нестандартная архитектура),
бот всё равно запустится — на резервном бэкенде `requests`, с предупреждением в логе.
Принудительный выбор бэкенда — переменная окружения `POC_HTTP_BACKEND` (`auto` / `curl_cffi` / `requests`).

## 🔌 Установка плагинов

Не устанавливайте плагины из непроверенных источников. Через систему плагинов злоумышленники могут получить полный доступ к Вашему устройству или аккаунту Playerok. Установка плагинов крайне проста.

1. Введите команду `/menu` в диалоге с ботом Telegram.
2. Нажмите кнопку 🧩 **Плагины**.
3. Нажмите кнопку ➕ **Добавить плагин**.
4. Отправьте или перешлите боту файл плагина.
